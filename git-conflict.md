# Отчёт о разрешении Git-конфликта

## Проект
Task Service — сервис управления задачами.

## Причина конфликта
Конфликт возник при объединении веток
update-description и improve-description
с основной веткой main.

В обеих ветках была изменена одна
и та же строка файла README.md.

## Конфликтующие изменения

Ветка update-description:
"Сервис для удобного управления
личными задачами."

Ветка improve-description:
"Сервис для планирования командных задач."

## Решение
Я открыл файл README.md, вручную
удалил маркеры конфликта и сохранил
согласованную версию описания:

"Сервис для управления личными
и командными задачами."

Затем выполнил команды:

git add README.md
git commit -m "Resolve README merge conflict"

## Результат
Конфликт успешно разрешён.
Изменения сохранены в ветке main.
