# План API

GET /tasks - получить список задач

POST /tasks - создать задачу

PUT /tasks/{id} - изменить задачу

DELETE /tasks/{id} - удалить задачу
## Создание задачи

Метод: POST /tasks

Пользователь отправляет название
и описание новой задачи.

При успешном создании сервер
возвращает код 201.
## Обработка ошибок

400 - Неверные данные пользователя

404 - Задача не найдена

500 - Внутренняя ошибка сервера
