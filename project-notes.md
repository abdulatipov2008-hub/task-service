# Заметки проекта

## Цель
Разработка сервиса управления задачами.

## Статусы задач
- Новая
- В работе
- Выполнена
## Функции управления задачами

Пользователь может:
- Создавать новые задачи
- Просматривать список задач
- Изменять описание задач
- Удалять выполненные задачи
## Приоритеты задач

Каждая задача может иметь приоритет:
- Низкий
- Средний
- Высокий

Задачи с высоким приоритетом
выполняются в первую очередь.
